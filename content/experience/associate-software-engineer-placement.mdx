## Highlights

- Independently designed and developed a Next.js tenant management dashboard, integrating existing Python AWS Lambda provisioning services and reducing tenant setup from a process spanning multiple weeks or sprints to approximately one sprint or less.
- Containerised and deployed the dashboard to AWS ECS using Docker and ECR, configuring ECS task definitions, modifying CloudFormation infrastructure and extensively adapting existing CodeBuild and CodePipeline workflows.
- Implemented authentication for the dashboard using Amazon Cognito, integrating SSO through SAML federation and OIDC to enable secure access for internal users.
- Implemented reusable role-based route authorisation across the main customer-facing React application, centralising permissions and feature-flag checks within the authentication context.
- Collaborated with two engineers on migrating the main customer-facing React application from Create React App/Webpack to Rsbuild/Rspack, reducing build times from over a minute to approximately five seconds.
- Developed C# backend functionality for multi-plan healthcare benefit calculations and investigated defects across existing application and backend services.
