## What I built

- Independently designed and developed a multi-service attendance system using React, TypeScript, Vite, a custom Go REST API built primarily with the standard library, and a separate Python/FastAPI facial recognition service.
- Proactively collaborated with Ulster University's IT administrators to integrate institutional Microsoft Entra ID single sign-on, implementing SAML/OIDC authentication and role-based authorisation.
- Implemented facial recognition using DeepFace and real-time single-use QR code verification using Server-Sent Events.
- Deployed the application on Azure using App Service, Azure SQL Database and Docker, configuring private networking for the facial recognition service and automated CI/CD pipelines using GitHub Actions.
